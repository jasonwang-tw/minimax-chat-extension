# Open Chat Hub Privacy Policy

Last updated: 2026-05-03

Open Chat Hub is a Chrome extension for multi-model AI chat, webpage reading, screenshots, OCR, translation, file analysis, knowledge management, vocabulary management, and optional settings sync.

## Data Stored Locally

The extension stores the following data in Chrome storage on your device:

- API keys that you enter for MiniMax, Gemini, OpenRouter, Brave Search, and Exa Search.
- Extension settings, custom prompts, custom commands, model settings, categories, and sync settings.
- Chat sessions, session summaries, long-term memories, knowledge base items, vocabulary items, attachments metadata, and OpenRouter usage/cost records.
- WordPress sync authorization tokens when you connect WordPress sync.

Some settings use `chrome.storage.sync`, which may be synchronized by Chrome if browser sync is enabled. Larger user data such as chat sessions, knowledge base items, vocabulary, session summaries, and usage records are stored in `chrome.storage.local` unless explicitly exported or backed up.

## Data Sent to Third Parties

Open Chat Hub sends data only when you use a feature that requires an external provider:

- MiniMax: chat text, prompts, conversation context, summaries, OCR post-processing, and related AI tasks when MiniMax is selected.
- OpenRouter: chat text, prompts, conversation context, supported attachments or PDF input, and model usage metadata when an OpenRouter model is selected.
- Gemini: screenshots, uploaded images, scanned/image PDF content, OCR requests, and image analysis prompts when visual analysis is used.
- Brave Search and Exa Search: search queries generated by you or by the Agent search flow.
- Google Translate TTS: message text chunks used for text-to-speech playback.
- WordPress Sync Bridge: settings backup payloads when you manually back up, restore, or enable sync.

Each provider processes data according to its own terms and privacy policy. Open Chat Hub does not control those providers.

## WordPress Sync

If you connect WordPress sync, the extension can back up settings, prompts, provider settings, memories, categories, custom commands, knowledge base items, and vocabulary items to the configured WordPress site.

Cloud backup currently does not include chat sessions or session summaries because those records can become large.

Current WordPress backup payloads may include API keys if you choose to back up settings. Treat the WordPress site as sensitive infrastructure and restrict access to trusted administrators. Client-side encrypted backup is planned before broader commercial release.

## Permissions

Open Chat Hub requests Chrome permissions for these purposes:

- `storage`: save settings, API keys, memories, knowledge base items, vocabulary, chat history, and usage records.
- `sidePanel`: show the AI workspace in Chrome's side panel.
- `activeTab`, `tabs`, and `scripting`: capture the active page, read selected page content, and support page-aware commands.
- `contextMenus`: add browser context menu actions.
- `identity`: support OAuth-style login flows for sync providers.
- Host permissions for AI/search/sync providers: call the APIs you configure.
- `<all_urls>` and content script access: support page reading, translation popup behavior, and screenshots across websites.

## What Open Chat Hub Does Not Do

- It does not sell user data.
- It does not use user data for advertising.
- It does not transfer user data for unrelated purposes.
- It does not collect payment card data.
- It does not run a hosted analytics service in the current local extension build.

## User Control

You can remove locally stored data by clearing extension storage from Chrome or by using the extension's built-in delete, clear, export, import, backup, restore, and logout controls where available.

If WordPress sync is connected, you can revoke tokens from the extension or from the WordPress admin page provided by the sync plugin.

## Contact

For questions, issues, or data deletion requests related to the bundled WordPress Sync Bridge on `jasonsbase.com`, contact the project maintainer through the repository or the site owner.
