對話設定

提示詞

你可以在這裡設定全域與各工具的系統提示詞。

自訂指令

使用 `/指令` 的方式快速插入模板或觸發行為，模板可使用 {input} 佔位。

長期記憶

AI 可以根據對話自動萃取值得保存的內容，也可以用 /remember 手動新增。

開啟後，每次對話結束會額外執行一次記憶萃取。

跨裝置同步（Phase 1）

目前以 WordPress 備援同步為主，支援手動/自動備份與還原。備份範圍包含設定、長期記憶、知識庫、單字簿與 Session 內容。

在其他裝置開啟 extension 時，自動拉取最新備份並套用，保持跨裝置資料一致。

鍵盤快捷鍵

以下為側邊欄支援的鍵盤快捷鍵。

Ctrl+F
開啟 / 關閉對話內搜尋
Ctrl+Alt+T
開啟 / 關閉目錄（TOC）
Enter
搜尋下一個結果
Shift+Enter
搜尋上一個結果
Esc
關閉搜尋列
←/→
Lightbox 圖片上 / 下一張

macOS 請將 Ctrl 替換為 Cmd。
