依模型統計

模型 請求 Input Output 費用

OpenRouter 費用表 用途分類說明 工具 / 資料分析：工具呼叫、資料整合、查詢、文件整理。 推理：數學、邏輯、多步推導、複雜決策。 Coding：寫程式、重構、產生程式碼。 Debug：讀錯誤訊息、定位 bug、修測試、追 stack trace。 長文本對話：長上下文、長文件、多輪對話。 長程式碼：大型檔案、跨檔案理解、長 context code review。 圖片 / PDF 分析：圖片、截圖、PDF 或檔案輸入後輸出文字分析。 生圖：輸出圖片，適合圖像生成或編修類任務。 語音：支援音訊輸入或音訊輸出。 低成本文字：適合大量摘要、改寫、分類、日常對話。 免費：OpenRouter 回傳 input / output 價格為 0 的模型。 高品質通用：適合重要回答、複雜任務與需要較高可靠性的場景。

Modalities 依 OpenRouter 模型資料分為 Input（可理解的輸入）與 Output（可生成的輸出）。
